# Baixador Universal

Programa para Windows que baixa vídeos (MP4) e músicas (MP3) do YouTube, Instagram, TikTok (sem marca d'água), Facebook, Pinterest, Twitch, SoundCloud, Dailymotion, Bluesky e outros sites.

**Baixar:** [Baixador-Universal.exe](https://github.com/outlier-apps/baixador-universal/releases/latest/download/Baixador-Universal.exe)

Precisa de uma chave de ativação, vendida na Basefy.

## Requisitos

- Windows 10 ou 11 (64 bits)
- Internet

## Como usar

1. Baixe e abra o `Baixador-Universal.exe`. Ele cria um atalho na Área de Trabalho.
2. Cole a chave de ativação e clique em **Ativar**.
3. Para o Instagram, clique em **Entrar no Instagram** e faça login uma vez (o login fica só no seu computador).
4. Cole o link, escolha MP4 ou MP3 e clique em **Baixar agora**.

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** e depois em **Executar assim mesmo**.

## Componentes de terceiros

Este programa inclui o [FFmpeg](https://ffmpeg.org) (licença GPL), cujo código-fonte está disponível em https://ffmpeg.org/download.html, e usa o [yt-dlp](https://github.com/yt-dlp/yt-dlp) (Unlicense).
